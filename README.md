# Shreya Sirigireddy portfolio

A single-page Next.js portfolio built around Shreya's fashion management, product development, and design experience.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The portraits, stickers, brand marks, and education logos are local assets in `public/images`. The page covers Shreya's background, skills, experience, projects, education, and contact details. Contact uses an email link; no form or backend is configured.
